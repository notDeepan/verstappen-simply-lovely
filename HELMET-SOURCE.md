The publisher identifies the model as Max Verstappen’s 2024 Imola Schuberth SF3 ABP, with three gold championship stars, helmet design by KV Designs and painting by JMD Helmets. The browser preview visibly shows the Red Bull graphics and mapped sponsor markings on the shell and visor. This remains an artist’s reconstruction, not a scan or manufacturer-certified replica.

Integration uses the creator-enabled public Embed function. No downloadable license was offered; therefore the geometry and textures have not been downloaded, repackaged or relicensed. The local ZIP contains the integration code, not the model. Attribution and a source link are displayed both in the section and the dialog. A locally editable/self-hosted asset would require a separate arrangement with the creator; no contact has been made or purchase initiated.

The 1920×1080 poster URL is the highest-resolution public thumbnail returned by Sketchfab’s model metadata API. It is loaded from the provider and is not modified or saved as an AI input. The public oEmbed endpoint independently returns the same model identity and an embeddable iframe.

The iframe mounts only after a visitor requests 3D and is removed when the dialog closes, the page exits, or Reference image is selected. dnt=1 follows the Embed dialog’s Disable user tracking option. Third-party hosting and internet access are required; the detailed model may load slowly on limited connections or GPUs. Reference image and View on Sketchfab are always available as alternatives.

Retired: generated fantasy helmet, procedural approximation, Heritage/Midnight livery switching, visor-opening control and artificial exploded shell. The earlier source is preserved under original/helmet-concept-v1/.

Readiness uses the official Sketchfab Viewer API 1.12.1 and viewerready event, not iframe load. The preview remains visible while loading. After 15 seconds without readiness, a direct interactive-view link appears; a later successful load still replaces the preview. In this in-app Chromium test the local iframe remained blank, but the standalone viewer rendered. This limitation is recorded rather than treating the preview as a successful 3D render.
